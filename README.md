# 欧州日本人クラブ速報

欧州7リーグで日本人選手が所属しているクラブについて、リーグ順位・成績・直近の試合結果をまとめて確認できるWebサイトです。各試合のハイライト動画はYouTubeですぐに探せます。

**サイト：https://taro-yoshioka.github.io/jp-euro-football/**

## 対象リーグ

- プレミアリーグ（イングランド）
- ラ・リーガ（スペイン）
- セリエA（イタリア）
- リーグ・アン（フランス）
- ブンデスリーガ（ドイツ）
- エールディビジ（オランダ）
- ベルギー・プロリーグ（ジュピラー・プロリーグ）

## 主な機能

- **日本人選手の自動検出**：各クラブの登録選手の国籍情報から日本人選手を自動で拾います。移籍があってもサイトを更新する必要はありません。
- **順位と成績**：順位、勝点、試合数、勝-分-敗、得点・失点、得失点差を表示します。1〜3位の順位は山吹色で表示します。
- **直近5試合の結果**：勝・分・敗のマークと、スコアを表示します。
- **ハイライト動画**：各試合の「▶ ハイライト」ボタンを押すと、その試合のハイライトをYouTubeで検索します。
- **日本人選手の得点**：日本人選手がゴールを決めた試合は、結果の文字が黄色になります（行にマウスを乗せると得点者が出ます。オウンゴールは含みません）。
- **背番号の色**：直近の試合で得点した選手の背番号は緑、得点していない選手はグレーで表示します。選手名を押すとYouTubeでその選手を検索します。
- **次の試合**：次節の日時（見ている端末の時刻設定で表示。日本なら日本時間）と対戦相手を表示します。
- **リーグ順位表**：各クラブのカードから、そのリーグ全体の順位表を開けます。日本人選手がいるクラブは色付きで表示します。
- **リーグ切り替え・ダークモード対応**：上部のタブでリーグを絞り込めます。表示はOSのライト／ダーク設定に合わせて切り替わります。

## データについて

- 順位・試合結果・選手情報・得点者は、ESPNの公開APIからページを開いたときに取得しています。APIキーは不要です。
- 取得したデータはブラウザに6時間保存されます。すぐに最新にしたいときは「最新に更新」ボタンを押してください。
- 国籍や得点者の情報はESPNのデータに従います。ESPN側で誤りがある場合は、サイトの表示もそのまま誤ります（明らかな誤りの選手は `index.html` の `EXCLUDE` で除外しています）。
- ハイライトボタンはYouTubeの検索結果を開きます。特定の動画に直接リンクしているわけではありません。

## 手元で動かす

`index.html` 1ファイルだけで動きます。ビルドやインストールは不要です。

```bash
python3 -m http.server 8765
```

起動後、ブラウザで http://localhost:8765/ を開いてください。
